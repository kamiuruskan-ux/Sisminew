PANDUAN INSTALASI CPANEL - SEKOLAH LRV

Sistem Informasi Manajemen Sekolah Terpadu (SIAKAD, LMS, CBT, SPP, & SPMB) Berbasis Laravel 13

Ringkasan Dokumen: Panduan praktis ini dirancang untuk memandu pengelola website / administrator sekolah dalam melakukan deploy dan instalasi aplikasi Sekolah LRV di web hosting cPanel menggunakan Web Setup Wizard interaktif.

1. Persyaratan Hosting & Server (Prerequisites)

Komponen Server Spesifikasi yang Dibutuhkan
PHP Version PHP 8.3+ atau PHP 8.4 (Sangat Wajib & Direkomendasikan)
Database Engine MySQL 5.7+ atau MariaDB 10.3+
Ekstensi PHP Wajib openssl, pdo_mysql, mbstring, tokenizer, xml, ctype, json, bcmath, fileinfo, gd, zip, curl
Resource Limit PHP memory_limit ≥ 256M (Recommended 512M), max_execution_time ≥ 300
Web Server Apache 2.4+ / Nginx (Support mod_rewrite)
Langkah 1 Setting Versi PHP & Ekstensi di cPanel
  1. Login ke cPanel akun hosting Anda.
  2. Cari menu Select PHP Version atau MultiPHP Manager.
  3. Ubah versi PHP domain Anda menjadi PHP 8.3 atau PHP 8.4.
  4. Masuk ke tab Extensions, centang dan aktifkan ekstensi berikut:
    • pdo_mysql, mbstring, gd, fileinfo, zip, xml, bcmath, openssl, curl, tokenizer.
  5. Masuk ke tab Options, atur konfigurasi nilai limit berikut:
memory_limit        = 512M
upload_max_filesize = 64M
post_max_size       = 64M
max_execution_time  = 300
Langkah 2 Setting Database MySQL di cPanel
  1. Buka menu MySQL® Database Wizard di cPanel.
  2. Buat Database: Masukkan nama database baru (misal: u123456_sekolahdb) lalu klik Next Step.
  3. Buat User Database: Masukkan nama user (misal: u123456_sekolahuser) dan buat Password yang kuat. Klik Create User.
  4. Hak Akses User: Centang opsi ALL PRIVILEGES lalu klik Make Changes.
  5. Simpan data kredensial database berikut untuk diisikan pada halaman Web Setup Wizard:
DB_HOST     = 127.0.0.1
DB_DATABASE = u123456_sekolahdb
DB_USERNAME = u123456_sekolahuser
DB_PASSWORD = PasswordDatabaseKuatAnda123!
Langkah 3 Unggah Berkas & Ekstrak Proyek
  1. Compress folder proyek sekolah_lrv di komputer Anda menjadi berkas .zip.
  2. Masuk ke File Manager cPanel → buka folder root domain (misal: public_html).
  3. Klik Upload, pilih file .zip dan tunggu hingga proses unggah selesai 100% (berwarna hijau).
  4. Klik kanan file .zip di File Manager lalu pilih Extract.
Langkah 4 Konfigurasi Redirection Document Root

Agar URL domain dapat diakses secara langsung tanpa memasukkan /system/public, buat atau edit file .htaccess pada root public_html:

<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteRule ^$ system/public/ [L]
    RewriteRule (.*) system/public/$1 [L]
</IfModule>
Langkah 5 Menjalankan Web Setup Wizard di Browser

Setelah berkas terunggah dan database dibuat, instalasi aplikasi dilakukan sepenuhnya melalui tampilan grafis Web Setup Wizard di browser:

  1. Buka browser dan akses alamat domain sekolah Anda: https://namadomain-sekolah.sch.id
  2. Sistem akan secara otomatis mendeteksi instalasi baru dan mengarahkan ke halaman Setup Wizard.
  3. Tahap 1 - Pemeriksaan Server: Wizard akan memeriksa otomatis kesesuaian versi PHP dan ekstensi server hosting. Klik Lanjutkan.
  4. Tahap 2 - Kredensial Database: Masukkan data database MySQL yang telah dibuat di cPanel (Host: 127.0.0.1, Nama Database, Username, dan Password). Klik Uji & Simpan Koneksi.
  5. Tahap 3 - Akun Super Admin & Identitas Sekolah: Masukkan Nama Sekolah, Email Admin, serta Password Super Admin yang diinginkan.
  6. Tahap 4 - Proses Otomatis: Setup Wizard akan secara otomatis mengkonfigurasi file .env, men-generate APP_KEY, mengeksekusi migrasi skema database, serta membuat seeder data awal secara instan.
Catatan: Seluruh konfigurasi environment .env, generate encryption key, serta pengisian tabel awal ditangani secara otomatis oleh Web Setup Wizard saat Anda menekan tombol Selesaikan Instalasi.
Langkah 6 Pengujian & Login Super Admin

Setelah Setup Wizard selesai, Anda dapat langsung mengakses seluruh portal aplikasi:

  • Website utama Sekolah: https://namadomain-sekolah.sch.id
  • Portal Admin: https://namadomain-sekolah.sch.id/login
  • Portal Siswa: https://namadomain-sekolah.sch.id/student/login
  • Portal Orang Tua: https://namadomain-sekolah.sch.id/parent/login

Login ke Panel Admin menggunakan Email & Password Super Admin yang telah Anda daftarkan pada saat proses Setup Wizard di atas.

Langkah 7 Troubleshooting Kendala Umum

1. Error 500 Internal Server Error: Cek permission folder system/storage dan system/bootstrap/cache (harus CHMOD 755/775). Cek log error pada system/storage/logs/laravel.log.

2. Error 404 Not Found pada Sub-halaman: Pastikan modul mod_rewrite aktif pada server Apache hosting dan file .htaccess terpasang dengan benar di root public_html.

3. QR Code & Gambar Tidak Muncul: Pastikan ekstensi PHP gd sudah diaktifkan di cPanel.
